# Woordenlijsten

Plaats hier je echte woordenlijst als `woorden.txt` (één woord per regel, UTF-8).
Bestanden `data/*.txt` staan in `.gitignore`, behalve `voorbeeld-woorden.txt`.

Controleer de licentie van de lijst voordat je die in de repository zet of meelevert.
Zie bijvoorbeeld OpenTaal (opentaal.org) voor een Nederlandse lijst met verbuigingsvormen.
